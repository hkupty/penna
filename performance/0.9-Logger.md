# 0.9 Logger Performance

This benchmark follows the same structure as the [previous one](performance/0.8-Logger.md), but with a few notable changes:

- Multi Threaded logger performance test was added;
    - For this test, 512 log messages are evenly divided across the threads.
- Log4j is using the file appender directly to `/dev/null`;
- The results were simplified, removing perf from the report.
- The tests were ran using JDK24 instead of JDK21

For the benchmark, those were the versions of the respective libraries that were tested:
slf4j    2.0.17
penna    0.9.0
logback  1.5.18
log4j2   2.25.1

## Test cases

The test cases are:

- `simple`: A simple log message;
- `modest`: The previous case with an added `Marker`;
- `moderate`: The previous case with an added `MDC` key-value pair and an argument formatted;
- `large`: The previous case with an added exception;
